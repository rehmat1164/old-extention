Download test extension ZIP ↘

Download SHA-256 checksum · Installation guide included inside the ZIP.

  1. Extract the ZIP into a permanent folder.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the extracted mete-run-local folder containing manifest.json.
  4. Disable the old extension. Sign in to Meta AI and Vibes, then click the Mete Run extension icon to open the native sidebar.

This page previews the real sidebar UI, not live generation. The installed extension uses your signed-in Chrome tabs. Nothing has been pushed to GitHub.

Generation still needs internet access. Prompts and source images go to Meta AI/Vibes when you start; no remote configuration or extra AI service is used.

Chrome requires a click to open a native sidebar for the first time. The extension automatically offers an open button on Meta AI and Vibes; it does not inject a full panel into either website.
